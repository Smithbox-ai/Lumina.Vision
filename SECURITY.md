# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in LuminaCalib, please **do not** open a public issue.

Instead, report it via [GitHub Security Advisories](../../security/advisories/new). This allows us to review and fix the issue privately before public disclosure.

### What to Include

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept (if safe to share)
- Affected version(s) or commit hash(es)
- Any suggested mitigation or fix

### Response Timeline

We aim to:

- Acknowledge the report within **5 business days**
- Provide an initial assessment within **14 days**
- Coordinate a disclosure timeline with the reporter

We appreciate responsible disclosure.
